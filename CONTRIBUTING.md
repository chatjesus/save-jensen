# Contributing

Open an issue with a concrete problem, or send a focused pull request. Keep both English and Chinese content in sync. Provide original sources and publication dates for factual timeline changes; distinguish facts from opinions. Do not add fabricated activity, testimonials or donation amounts.

Run `python3 build.py` and, from `server/`, `npm ci && npm test`. For UI changes, check both languages at narrow mobile and desktop widths, keyboard navigation and reduced motion. Test interactions against the local in-memory server, not the public site's counters or message wall.

Never submit credentials, deployment identifiers, private contact information or user content. Retain image attribution and licenses. The sent letter is an archival record: annotate later developments separately rather than rewriting what was sent.

Changes to project code are contributed under the MIT license. New third-party assets must carry clear, compatible license and attribution records.
